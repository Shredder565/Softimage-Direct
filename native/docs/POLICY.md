# Native track policy

**Hard rule:** Softimage-faithful **original** AfterImage code only.

| Allowed | Forbidden |
|---------|-----------|
| Dump / Ghidra / REA **behavior tables** (Names, arg shapes, paths, HWND labels) | Softimage binaries |
| Architecture *style* (Win32, SP2-era desktop UX) | Softimage source |
| Clean-room handlers keyed by attested Names | Decompiled C++ / Ghidra paste |

Softimage paste override requests are **refused**.

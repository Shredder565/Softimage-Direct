# Coverage ledger: Softimage 2015 SP2 → AfterImage

The single work queue for `si-analyst` and `afterimage-wire` (see [README.md](./README.md)).
Work top to bottom within each priority. Split a row into sub-rows (`CMD-03a`, …) as soon
as you start on it; a row is only `WIRED` when a compare harness proves it against goldens.

Earlier residual work (A1–C6) stays in [../ghidra/residual-index.md](../ghidra/residual-index.md).
